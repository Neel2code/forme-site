# FORMÉ site

Scroll-driven 3D landing page for the FORMÉ iOS app. three.js + GSAP ScrollTrigger + Lenis, built with Vite.

```
npm install
npm run dev      # local
npm run build    # outputs dist/
```
`public/p/` holds cut-outs of real closet pieces. `privacy.html` is the app's privacy policy and terms.
